Task: Apply conditional coloring (Green for Positive, Red for Negative) to financial values across the Dashboard and Reports.

Please make the following updates to JS.html:

1. Add a Global Formatting Function:
Under the // ===== CORE FUNCTIONS ===== header, add this new utility function. This will format numbers into currency and wrap them in the correct color:

JavaScript
function formatMoney(amount) {
  const num = Number(amount) || 0;
  if (num > 0) return '<span style="color: var(--success); font-weight: 700;">+₹' + Math.abs(num).toFixed(2) + '</span>';
  if (num < 0) return '<span style="color: var(--danger); font-weight: 700;">-₹' + Math.abs(num).toFixed(2) + '</span>';
  return '<span style="color: var(--navy-primary); font-weight: 700;">₹0.00</span>';
}
