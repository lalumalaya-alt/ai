Task: Add a "Reset Filters" button to the Reports tab that clears all search criteria and reloads the full report.

Please make the following updates to the frontend files:

1. Update Index.html (HTML Structure):
In the Reports tab, locate the filter grid section (where the Start Date, End Date, Transaction Type, and Category inputs are). Add a new button labeled "Reset Filters". A logical place to put this is right next to the Search box or at the bottom of the filter area. Attach an onclick event to this button that will trigger a new reset function.

2. Update JS.html (Create the Reset Logic):
At the bottom of your JavaScript file, create a new function called resetReportFilters.

3. Update JS.html (Clear the Inputs):
Inside this new function, write the logic to clear all the filter inputs:

Set the Start Date and End Date values to empty strings.

Set the Transaction Type and Category dropdowns back to their default, unselected placeholder states.

Set the Search text box to an empty string.

Tenant Filter: If you are using the multi-select checkboxes, loop through them and uncheck all of them. (If you are still using the single dropdown, reset it to "All").

4. Update JS.html (Reload the Data):
As the very last step inside your new resetReportFilters function, call your existing applyReportFilters function. This will automatically recalculate the totals and redraw the table using the newly cleared filters, showing all data once again.
